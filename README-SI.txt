THE STAGE CAFE WEBSITE FILES

1. GitHub repository eke root folder ekata me files 3ma upload karanna:
   index.html
   menu.json
   photos.json

2. Restaurant logo eka root folder eke stage-cafe-logo.jpg kiyala thiyenna one.
   (Danata repository eke root eke logo file eka thiyenawa nam ayeth upload karanna epa.)

3. Photos maru karanna:
   photos.json open karala image URL eka maru karanna. title eka wenas karannath puluwan.

4. Menu items / prices maru karanna:
   menu.json edit karanna. Rs. 0 sample prices real prices walin maru karanna.
   Same price thiyena items unath wen wenama list karanna puluwan.

5. WhatsApp orders:
   index.html eke RESTAURANT_WHATSAPP = "" thanata country code ekka number eka danna.
   Udaharanayak: 94771234567 (me number eka example ekak pamanai).
   WhatsApp order link eka open wenawa; order eka send karanne customer.

- Me version eke WhatsApp order flow eka use karanawa.
